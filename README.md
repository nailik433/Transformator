# Transformator-Labor

Interaktive Einstiegs-Animation für den Physikunterricht: Warum erzeugt ein Transformator nur mit Wechselspannung eine Spannung im Sekundärstromkreis?

**Live:** https://nailik433.github.io/Transformator/

Drei Schritte:
1. **Gleichspannung** – der Eisenkern ist ein Magnet, aber die Lampe bleibt dunkel. Beim Umstecken der Kabel blitzt sie kurz auf.
2. **Ganz oft umstecken** – automatisches Umpolen lässt die Lampe immer wieder aufblitzen.
3. **Wechselspannung** – polt sich von selbst ständig um, die Lampe leuchtet dauerhaft.

Eine einzelne HTML-Datei ohne Abhängigkeiten (nur Google Fonts). Läuft auch offline im Browser.
